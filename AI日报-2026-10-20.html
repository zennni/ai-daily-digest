🥚 每日AI前沿日报

今日主题词：速度 × 成本边疆。10 月 19 日两家把「更快更便宜」做成产品叙事：MiniMax 正式发布 M3.1 Flash（早期匿名代号 Space Bunny），官方称线上推理近 3 倍速、用量成本约降 70%，定价 0.15／0.60 美元每百万输入／输出 token、缓存读 0.015；本站按 AA v4.3.2 记 42 分、主榜约第 43、性价比 75（A）。同日 Inception Labs 放出扩散式 LLM Mercury 3：厂商称在 NVIDIA GPU 上约 1,068 token／秒、1M 上下文，对标 GPT-6 Luna／Claude Haiku 5.5，首发五折 0.10／0.35。Cloudflare 则另开一条「System One」线——Clairic 抽取模型在 Workers AI 预览上线，单次前向、只收输入价。资本侧同样在抢时钟：路透称 OpenAI 拟加速完成约 300 亿美元融资、估值望超 1.4 万亿，赶在 Anthropic 约 11 月中旬 IPO 披露前锁定同一批长钱。叙事从「再堆几个智能分」切到「谁能把延迟和账单压到可规模化」——与社区里「智力饱和、流量更跟成本／速度走」的讨论同向。

🔥 今日看点

  • MiniMax M3.1 Flash 正式发布：Agent／编程／电脑操作／安全代际跃升，价约 0.15／0.60

    MiniMax 10 月 19 日宣布 M3.1 Flash 上线；早期匿名跑过超 200 万亿 token 的 Space Bunny 即其前身。官方称相对前代 Flash，Agent 协同、编程、Computer Use 与网络安全「代际」提升，线上推理近 3 倍速、用量成本约降 70%；日常输出可达 200+ TPS、P50 约 170+ TPS。厂商自评：DeepSWE v1.1 73.7%、BankerToolBench 76.2、OSWorld V2 61.7、ALE 29.6（称中国模型这两项第一）、CyberGym 82%。挂牌价每百万 token：输入 0.15、输出 0.60、缓存读 0.015 美元；API／M Plan／MiniMax Code 可用，权重「稍后放出」。本站榜单以 AA Intelligence Index v4.3.2 记 42 分、任务成本约 0.30、性价比 75（A）、主榜约第 43。

  • Inception Mercury 3：扩散 LLM 扩到 1M 上下文，约 1,068 TPS，对标 Luna／Haiku

    Inception Labs 同日发布 Mercury 3，称其为迄今最强商用扩散式语言模型：参数规模相对 Mercury 1 扩大 40 倍以上，智能约 3 倍提升，却仍保持千级 token／秒；厂商写明 NVIDIA GPU 上约 1,068 TPS，上下文从 Mercury 2.5 的 260K 扩到 1M。质量上自称持平或优于速度优化档的 GPT-6 Luna 与 Claude Haiku 5.5。正式价 0.20／0.70，首发五折 0.10／0.35，缓存输入再九折。已上 Inception API、OpenRouter、Baseten、Vercel AI Gateway，OpenAI 兼容。早期案例覆盖浏览器智能体、实时辅导、搜索与客服——把「扩散能不能规模化」从论文问题推进到可替换的生产路由。

  • OpenAI 加速约 300 亿美元融资，估值望超 1.4 万亿，抢在 Anthropic IPO 前

    路透 10 月 19／20 日援引知情人士：OpenAI 正以异常快节奏推进约 300 亿美元融资，估值目标逾 1.4 万亿美元，并希望赶在 Anthropic 约 11 月中旬上市披露更完整财务前锁定承诺。SoftBank、阿布扎比 MGX 等老股东据称在谈跟投；公司向投资者展示 GPT-6 Astra 后年化收入约 500 亿、年底望 700 亿的口径。Anthropic 此前年化收入约 650 亿（至 7 月）、Q3 收入 168 亿，但环比增速放缓已令部分投资人把上市估值预期从约 2 万亿下调到约 1.5 万亿量级。两家抢同一批长钱与主权基金，把「万亿估值竞赛」压成以周计的时间表。

  • Cloudflare Clairic：System One「抽取模型」上 Workers AI，只收输入、不出 token

    Cloudflare 10 月 19 日预览 Clairic（@cf/cloudflare/clairic）：在 TypeSafe Jev／自家 Clef 等「决策模型」之外，新开一类 System One 抽取模型——单次前向、不生成 token，按 schema 返回带置信度与 p_null 的文本 span／数字／日期／列表／估计／预测。支持文本 + 最多 4 张图；示例管道（Clairic→Clef→GLM-5.3）相对全程 LLM 端到端约快 3.2 倍、成本约降一半。定价按输入计（约 0.10 美元／百万输入 token、无输出价），权重称将开源。它把「发票总额／送达日／维修估价」从 LLM JSON 抽取的脆弱环节，改写成可审计的类型化回归接口。

Self-HPO：交替优化 harness 与策略的自演化编码智能体 / Self-Evolving Coding Agents via Harness-Policy Optimization

Zhepei Wei, Wenlin Yao, Baolin Peng, Danqing Wang, Qianhui Wu, Hao Cheng, Yu Meng, Jianfeng Gao 等

微软亚研等提出 Self-HPO：编码智能体在 H-step 用当前策略分析失败并提出 harness 候选，P-step 在选定 harness 下做 RL，再把从未解开的难题当作下一轮搜索集。Qwen3.5-35B-A3B 平均 resolve 从 57.8% 提到 64.8%（SWE-Verified 61.0→69.5）；外部用 Opus 4.8 提 harness 还可到 71.6%。消融显示「evolve 搜索集」与「联合优化」增益可叠加。代码：MSR-Orchard/Self-HPO。

arXiv / 论文

Harness Policy Distillation：把运行时语义写进策略蒸馏 / Harness Policy Distillation: Aligning Agent Policies with Runtime Semantics

Junze Zhu, Weihao Chen, Zhiyang Zhou, Zhen Wu, Xinyu Dai

南大团队提出 HPD：在回放边界把 harness 控制状态编译成 privileged control document，经 harness 校验后与动作联合监督（T/I/R 三视图）。Qwen3-8B 在 TRAJECT-Bench／Pi 上自主任务成功率 3.09%→22.98%，运行时合规 19.90%→49.23%，优于 OPD 等基线；跨 BFCL 零样本仍保持优势。部署时仍走原生 harness，无需外挂控制文档。

arXiv / 论文

Harness² 续：开放世界里的递归 harness 优化（本周对照） / Harness2: Recursive Agent Harnessing for an Open World

Ruiyao Xu, Yanfei Chen, Zhongying CuiZhu 等

Google Research 的 Harness² 仍是本周 harness 讨论的工程参照：冻结权重，用 Propose–Probe–Compose 改提示／守卫／记忆／工具。与 Self-HPO「改 harness + 训策略」形成对照——一边只动外围，一边让策略自己当 proposer。

arXiv / 论文

LAGO：带可复用增长选项的语言智能体 / LAGO: Language Agents with Reusable Growing Options

见 arXiv 2610.19843

面向长程任务的选项（option）学习框架，强调跨任务可复用的子策略增长，减轻每步重规划的开销。与「速度／成本」产品叙事互补：模型侧降延迟之外，智能体侧也在压缩决策层级。
