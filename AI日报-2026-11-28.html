Langfuse 11 月 27 日更新日志宣布，组织的所有者和管理员可以在 Organization Settings > Models 里为所有项目统一填写模型定义，而不必在每个项目里重复维护自定义条目。自定义或谈判后的费率只需定义一次（也可从 Langfuse 默认项克隆），各项目据此推断成本。匹配顺序是项目、再组织、再 Langfuse 默认；若要只改一个项目，可在 Project Settings > Models 克隆组织级定义后覆盖。组织级定义也可通过 Organization Models API 同步；项目 Models API 现在为每条模型返回 scope 字段，并开始弃用 isLangfuseManaged。

补记：Visual Studio Code 1.148 发布，智能体宿主对话更快，并支持全屏 MCP Apps

Visual Studio Code 1.148 稳定版于 11 月 25 日发布。官方更新说明称，Agent Host 中对话开始响应的平均时间比上一稳定版快 30%，并已接近旧版 Local harness 约 5% 的差距。预览功能 sessions.keepAwakeWhileWorking 可在智能体工作期间阻止受支持主机进入空闲休眠，默认在插电时生效。MCP 方面，MCP Apps 增加全屏按钮，可把应用移到编辑器区域或 Agents 窗口的次侧栏。实验功能还包括为智能体会话创建 Dev Container、为远程主机配置沙箱配置，以及在远程主机上清理工作树。Agent Host Protocol 更新到 1.1.0，说明中写明支持 SEP-2640 Skills over MCP。此条落在前日窗口，昨日早六、早八未收，本期补记。
