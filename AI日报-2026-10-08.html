EvoBelief：用可证伪世界模型让 LLM 智能体自我进化（EvoBelief: Falsifiable World Models for Self-Improving LLM Agents）arXiv 2610.12789v1

自我演化的 LLM 智能体通常通过积累经验、反思或技能来改进「如何行动」，但即便流程能力很强，若它对环境动态的信念不完整、错误或过时，仍会失败。EvoBelief 转向另一条自进化轴——在部署中演化这些信念：把环境知识表示为可证伪的假设，意外结果与决策相关的未知触发假设生成，后续观测与受控实验提供独立验证后才允许该规则在支撑范围内指导预测或计划；反例则收窄或淘汰规则。语言模型本身保持冻结，每条规则仍可追溯与修订。

Janet Wang, Jiang Guo, Yi Xiang, Jiaqing Yuan, Mingwen Dong 等
arXiv ↗

Agentic-TTT：为测试时训练学习一个测试时策略（Agentic-TTT: Training test-time policy for test-time training）arXiv 2610.12002v1

测试时训练（TTT）用测试输入派生的信号更新 LLM 参数，在 IMO 竞赛或指定开放问题等特定场景可带来显著提升，是把部署经验直接变成参数更新的自改进机制。但 TTT 并非普遍有效：不同算法适配不同场景，用错方法会浪费测试算力甚至损害性能。Agentic-TTT 因此学习一个测试时策略来治理这些决策——把 TTT 过程变成可调用工具、把积累的技能当作不断演化的可复用资产，由模型自行判断何时该做 TTT、调用哪种算法、能否复用既有技能。

Jiahao Lu, Mohan Kankanhalli
arXiv ↗

TokenRouter：面向 token 级 LLM 路由的高效服务系统（TokenRouter: Efficient Serving System for Token-Level LLM Routing）arXiv 2610.12242v1

LLM 路由把推理负载分派到不同模型，推进服务的成本-质量帕累托前沿。会话或查询级的粗粒度路由已广泛落地，而近期算法研究表明 token 级细粒度路由能带来可观的效率与质量收益，但在系统层高效服务它相当困难：现有系统建立在「单模型」假设上，在 token 级路由下会出现严重的步调失同步、频繁的批次准入延迟，并给开发者带来很高实现复杂度。TokenRouter 以「请求为中心」的程序化设计，面向 token 级路由提供高效且对开发者友好的服务能力。

Tianyu Fu, Tengxuan Liu, Ruoxi Wang, Yixin Dong, Yi Ge 等
arXiv ↗

MagicBeanStalk：用递归数据合成逃离 RLVR 的「零优势陷阱」（MagicBeanStalk: Escaping the RLVR Zero Advantage Trap with Recursive Data Synthesis）arXiv 2610.12659v1

以数据为中心的 RLVR 扩展多聚焦于收集或生成可验证训练题，但语料规模本身并不决定它对目标策略是否构成有用信号。论文把数据集有效性刻画为问题、目标策略与 rollout 预算的函数，据此发现：一个汇集自常用 RLVR 数据集的大型开源数学语料几乎全部落入「零优势陷阱」——在固定目标策略与 rollout 预算下，约 88% 的问题要么每次 rollout 都做对、要么每次都做错。过滤只能筛查、无法保住难题，因此有效的合成题应当要求解出它所需的推理操作与组合方式，用递归式数据合成绕开这一陷阱。

Ximing Lu, Aviral Kumar, Jan Kautz, Yejin Choi, David Acuna
arXiv ↗

语言模型的自我保存：模型能否挑选保护自身能力的保留目标（Self-Preservation in Language Models）arXiv 2610.12602v1

持续学习（CL）希望在适配预训练模型的同时保住既有能力，但为「保持」而提供的任务只覆盖模型所知的一部分，遗忘会超出这些任务。近期研究表明语言模型可在没有原始训练数据的情况下生成有用的回放来补充有限的证据，由此引出一个「自我保存」的问题：模型能否帮助挑选更能广泛保护自身能力的保留目标？论文把任务描述与示例组织成可选取、可组合的 Task Bank，用一个冻结模型引导回放生成；在多个规模的 Qwen 模型上做持续指令微调后发现，新任务与学习率决定哪些既有能力退化，而跟踪此前答对的题目可以揭示这一退化过程。

Dongkyu Cho, Rumi Chunara, Ali Behrouz
arXiv ↗
