美团发布 LongCat-2.5：1.6 万亿参数、全程国产算力

11 月 2 日美团发布面向长程智能体任务的原生多模态大模型 LongCat-2.5，总参数 1.6 万亿，训练全程由国产算力完成。模型强化原生视觉理解与智能体编程，中训练阶段最长用 1M token 序列做长上下文训练；针对国产卡单卡显存偏小，围绕超节点优化通信，官方称长上下文 SFT 单卡训练吞吐量较 DDP 基线提升 86%。推理采用 W4A4，线上压测相对 W8A8 输入与逐 token 吞吐约提升四成。官方称多项主流基准成绩介于 Claude Opus 4.8 与 Opus 5 之间、部分超过 Opus 5；用户可在 LongCat.ai 体验，开发者可通过同步上线的 API 调用。围绕主业，美团还推出基于 LongCat 的商家 AI 经营工作台「妙手」。

代数世界模型：从探索到证明

Algebraic World Model: From Exploration to Proofs

清华姚期智团队提出 AWM：在未知环境中交互、写出可执行 Python 假设，再整理成带类型的对象与规则，并用范畴论引导的变换简化后，在 Lean 4 中形式化以证明可达性与不可能性。在两个特制「无解」关卡上，六次运行全部给出内核核验的封闭证明；Opus 5.5 与 GPT-6 Astra 十二次基线无一给出。25 个公开 ARC-AGI-3 游戏共 183 关上，配合 Opus 5 得分 99.9，认证通关轨迹动作数仅为人类基线的 43%。

Guancheng Pan, Qixin Tan, Yang Yuan, Andrew C. Yao

潜空间稀疏注意力：面向亚二次超长上下文

Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention

传统稀疏注意力的索引器仍要对每个 query 扫描全部（或全部块）key，到千万级上下文时索引本身占满预填时间。LSA 把 key 在学习到的潜空间做层次聚类，query 只搜簇；D-LSA 可蒸馏进已有模型，N-LSA 可仅靠 next-token 损失原生训练。在 GLM-5.3-Flash 上 10M token 时，单层预填相对其原稀疏注意力加速 22.7×、解码 4.6×；在 Qwen-3.8-27B 上相对全注意力分别达 72.4× 与 42.5×。

Ales Kubicek, Andrea Caciolai, Liangzu Peng 等

ACCT：同族异规模模型之间的非对称上下文迁移

ACCT: Asymmetric Cross-LLM Context Transfer

异构部署里换模型常要重算整段上下文。ACCT 把源模型已算好的 KV 转成目标模型可直接消费的稀疏 KV：Cartographer 按层/头给 token 打分，Allocator 在总预算下分配容量，Compiler 做跨规模变换。约 19K 上下文时，KV 转换相对目标预填加速 6.5–21.2×；在 4× 压缩（KV 槽位减 75%）下，多项任务接近甚至超过目标模型原生全上下文表现。

Yuzhe Liu, Haolin Tian, Tonghan Wang
