AWS 推出本地 AWS Emulator：与云端同一套 API，官方称由智能体对照模型编写并维护

亚马逊云科技 11 月 11 日在 AWS News Blog 宣布推出 AWS Emulator：在本机提供本地 HTTPS 终点，AWS CLI、SDK 和编程智能体用与云端相同的 API 发请求，无需先部署到区域。该模拟器用 Rust 实现，对已在 AWS API models 仓库公开模型的服务提供接口；Linux 可装 RPM 或 Debian 包，macOS 与 Windows 需按文档在 Docker 中运行。启动后只监听 127.0.0.1:9297，并生成以 EMULATOR 开头的访问密钥。官方强调没有额外服务费，只有真正部署到 AWS 时才为云资源付费；源码已放到 GitHub，11 月 12 日的更新补上了仓库链接。构建方式上，官方称模拟器由智能体借助 Amazon Bedrock AgentCore Runtime、CodePipeline 和 CodeCommit，对照公开 API 模型编写并维护，另有独立的安全智能体做对抗式审查，发布前跑保真测试。官方也划了边界：它不按 AWS 的方式评估 IAM 与基于资源的策略，一次实例只作为单一账户，跨账户、跨区域行为不支持；不要用它来测试应用是否安全，上线前仍须在真实 AWS 上验证。
