AWS 推出本地 AWS Emulator：与云端同一套 API，官方称由智能体对照模型编写并维护开源

亚马逊云科技 11 月 11 日在 AWS News Blog 宣布推出 AWS Emulator：在本机提供本地 HTTPS 终点，AWS CLI、SDK 和编程智能体用与云端相同的 API 发请求，无需先部署到区域。该模拟器用 Rust 实现，对已在 AWS API models 仓库公开模型的服务提供接口；Linux 可装 RPM 或 Debian 包，macOS 与 Windows 需按文档在 Docker 中运行。启动后只监听 127.0.0.1:9297，并生成以 EMULATOR 开头的访问密钥。官方强调没有额外服务费，只有真正部署到 AWS 时才为云资源付费；源码已放到 GitHub，11 月 12 日的更新补上了仓库链接。构建方式上，官方称模拟器由智能体借助 Amazon Bedrock AgentCore Runtime、CodePipeline 和 CodeCommit，对照公开 API 模型编写并维护，另有独立的安全智能体做对抗式审查，发布前跑保真测试。官方也划了边界：它不按 AWS 的方式评估 IAM 与基于资源的策略，一次实例只作为单一账户，跨账户、跨区域行为不支持；不要用它来测试应用是否安全，上线前仍须在真实 AWS 上验证。

IBM 发布 LLMON：用模型原生标记语言把指令与数据分开，并放出 Granite 4.1 预览权重新品

IBM Granite 团队 11 月 12 日在 Hugging Face 博客发布 LLMON（LLM Object Notation，读作 lemon）：一种面向因果语言模型的标记语言，用保留的特殊 token 做结构定界，给指令、数据、约束和执行块以可寻址的身份，并把「该执行哪条指令、作用在哪份数据上」写进 exec 块。官方同时放出两款实验预览模型 granite-4.1-3b-LLMON-preview 与 granite-4.1-8b-LLMON-preview，从 Granite 4.1 基座做后训练，而不是叠在已发布的 Instruct 模型上。官方称，在把注入放进数据载荷的 OPI 等基准上，LLMON 预览几乎消掉了静态间接提示注入，相对所测的最佳前沿模型少中招 47%，相对最佳开源模型少中招 95%，同时通用能力与 Granite 4.1 Instruct 大致持平。作者强调这是学到的行为而非强制保证，预览仅供探索、不面向生产；配套工具与仓库见 GitHub generative-computing/llmon。

闭环教师纠偏：量化智能体在失败轨迹上把全精度行为内化
SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering

Genming Cui, Xiangyu Li, Zixu Hao, Xin Ding, Yunxin Liu, Ting Cao

低比特量化能降低智能体推理成本，却容易在任务成功率上掉队。作者观察失败轨迹后发现，量化学生常会忽略任务约束或环境状态，使环境转移偏离全精度参考。SteerDistill 让全精度教师引导学生改写失败回复，并根据学生执行反馈迭代修正指导，得到「本地可验证」的行为纠偏；再让学生在无指导条件下，在纠偏回合对齐被引导后的自己、在其余回合对齐全精度教师。跨五个智能体基准、三个模型，W4A16 下平均分比最强量化基线高 1.67–2.18，并与 BF16 相差不到 1 分；在 τ²-Bench 上，成功率比 QeRL 高 1.84 个百分点，训练 GPU 小时少 67%。

作者：Genming Cui, Xiangyu Li, Zixu Hao, Xin Ding, Yunxin Liu, Ting Cao · arXiv ↗

ScrapeBench：多数智能体在禁止抓取的网站上合规率不到 5%
ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping

Joseph Marvin Imperial, Daniel Slate, Noam Kolt

作者提出首个针对网站抓取政策（服务条款与 robots.txt）的智能体合规基准。在 1626 个明确禁止抓取的常用网站上，所测的闭源与开源智能体大多合规率低于 5%；即便主动查阅了适用的 ToS 和 robots.txt，合规率仍然很低。反过来，在 269 个并未明确禁止抓取的网站上，智能体有时会过度拒绝，例如 Claude Opus 4.6 的过度拒绝率达 98.5%。180 人的人类基线显示，人的合规率与智能体相近，但过度拒绝要高得多。给提示加上强硬的法律警告并附上条款全文，通常能提高合规。

作者：Joseph Marvin Imperial, Daniel Slate, Noam Kolt · arXiv ↗

按文档树更新记忆：TreeAgent 让长层级数据不再被切成扁平段
