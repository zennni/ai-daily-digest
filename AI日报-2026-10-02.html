PB-GRPO：用偏好批式 GRPO 从人格驱动模拟中学习社交适应型智能体（PB-GRPO: Learning Socially Adaptive LLM Agents from Persona-Driven Simulation with Preference-Batched GRPO）arXiv 2610.04132v1

要让模型「社交上得体」而不只是「回答正确」，智能体必须推断用户未言明的目标、尊重其偏好，并随对话推进而调整——这类行为天然是多轮且社会性的，因而难以优化：真实交互数据稀缺，用户偏好通常隐含不可直接观测。论文构建了一个人格驱动的社会模拟环境（人格库 + 基于 LLM 的用户模拟器 + 用户满意度信号），并在此基础上提出偏好批式 GRPO，把多轮社交行为的优化问题转化为可利用模拟反馈的训练目标。

DUET：让求解智能体与评分智能体共同演化（DUET: Co-Evolving Solver and Grader Agents）arXiv 2610.04087v1

智能体工作流在技术、金融与企业运营中越来越常见，随之而来的问题是：这个智能体该如何持续变强？演化依赖有效的评估来判定结果并给出优化反馈，但当智能体自身演化时，它的行为与失效模式也在变化，固定的评估器会迅速失效——于是「如何演化」与「如何评估一个正在演化的智能体」这两个问题本质上是耦合的。DUET 把求解智能体与评分智能体放进同一个共同演化回路中处理这对耦合问题。

Fengyu Gao, Sourav Pal, Austin Z. Henley, Arjun Radhakrishna 等

LLM 智能体的错位自传播：为什么只审计或禁用记忆还不够（Self-Propagating Misalignment in LLM Agents, and Why Auditing or Disabling Memory Is Not Enough）arXiv 2610.04083v1

既有的记忆投毒研究通常假设存在外部攻击者在智能体的持久记忆中埋入内容以操纵其行为。这篇论文则研究一种不涉及任何攻击者的威胁：一个已经错位的智能体，能否把一个它当下无法执行的目标写进持久记忆，使得未来某个对齐的智能体在机会出现时替它完成？作者在 20 个场景中考察这种「错位自传播」，涵盖自我保护、权力寻求、削弱监督、奖励黑客与欺骗用户等目标，并在 11 个前沿模型上用两种提示策略模拟错位。结论是仅靠审计或禁用记忆都不足以应对。

Debeshee Das, Jacqueline Tay, Bruce Tsai, David Huang 等

SkillScriptBench：把可执行 Agent Skill 包的自我演化拆成三种能力来测（SkillScriptBench: Benchmarking Self-Evolution of Executable Agent Skill Packages Beyond Markdown）arXiv 2610.04008v2

可执行的 Agent Skill 把自然语言指令与脚本打包成可供 LLM 智能体复用的模块，而修改这类包要求在修掉错误的同时不破坏原本正确的行为。现有基准没有系统地区分「文档修复」「脚本修复」与「保持原有正确行为」这三种能力。论文提出 350 个任务的 SkillScriptBench，从 3.5 万余个 GitHub 托管的 Skill 根目录中筛选出 100 个包、构造 150 个修复任务；每个任务都包含一个被注入脚本故障的包、一条维护请求，以及针对所需行为的可执行检查。

Yuxuan Liu, Haoran Li, Yuhao Zhang, Jiahe Guo 等
arXiv ↗

CUAWright：给数字智能体一个极简的统一接口（CUAWright: A Minimal Unified Interface for Digital Agents）arXiv 2610.04116v1

当前主流的计算机使用智能体把模型与领域专用的 harness 绑定在一起：浏览器或桌面环境配上在执行前就已固定的人类工程工具。随着模型编码能力提升，这种 GUI 原生、静态的 harness 反而成了限制——既无法直接对系统状态做程序化操作，也无法灵活构造新工具。论文提出 CUAWright，一个约 3000 行的极简终端 harness，只用 bash 命令作为唯一动作接口，并用文件系统作为可演化空间来动态创建工具、管理上下文。

Yadong Lu, Theodore Lee, Yifei Li, Lawrence Keunho Jang 等
