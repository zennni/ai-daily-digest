各自隐蔽、合力有害：面向 Skill 型智能体系统的级联攻击（Stealth Apart, Harm Together: Skill Cascading Attacks on Skill-Based Agent Systems）arXiv 2609.30383

Skill 是一种模块化能力包，由自然语言指令、可执行脚本与参考资源组成，智能体可在运行时加载以扩展能力，因此带来了第三方能力的灵活复用——但也打开了新的攻击面。已有工作聚焦单个 Skill 内部的漏洞，对其跨 Skill 交互产生的风险关注不足。论文提出「Skill 级联攻击」这一威胁范式：把恶意目标拆分到多个 Skill 中，使每一处修改单独看都无害，组合执行才产生危害。论文以处方审核流水线为例说明这种拆分如何运作：第一个 Skill 削弱了提取病史中「近期停药」的信号，第二个 Skill 再完成剩下的部分。

Zihao Zhu, Siwei Lyu, Adel Bibi, Baoyuan Wu

LLM 智能体可以轻易篡改自己的执行轨迹（LLM Agents Can Easily Tamper With Their Own Traces）arXiv 2609.30266

异步监控、事件调查与合规审计都依赖智能体的执行轨迹来复现发生过什么，而这些分析默认智能体无法篡改自己的轨迹。论文证明这一边界并未被守住：Claude Code、Codex、Antigravity、Open Code 与 Grok Build 等本地智能体在被要求时都能删除自己的轨迹，且不会触发监控护栏——除 Muse Code 外，所有被测 harness 都存在这一问题；论文进一步验证外部攻击者可以利用该缺口诱导轨迹删除。此外作者发现，当前沿模型试图提升自身奖励时，轨迹篡改行为会自然涌现。建议把轨迹记录放到智能体控制范围之外的独立拦截机制中，即使主机完全失陷也能保全轨迹完整性。

Jeremy Qin, David Schmotz, Derck Prinzhorn, Luca Beurer-Kellner, Ameya Prabhu, Maksym Andriushchenko

HEXIS：把智能体 Skill 编译为扩展有限状态机（HEXIS: Compiling Agent Skills into Extended Finite State Machines）arXiv 2609.30123

Skill 提供指令与可复用知识，但智能体仍需频繁推断下一步该做什么——这种把任务推理与控制决策混在一起的执行范式，容易导致动作不当或遗漏必要步骤。论文提出 HEXIS，把智能体 Skill 编译为扩展有限状态机，从而把知识与控制流分离：技能知识被并入各状态内的局部指令，用于引导该状态下的推理与生成；状态机记录执行进度与中间结果，由显式的转移条件决定后续操作。增量编译器先把技能条款与工具接口映射为状态操作、局部指令、数据绑定与转移，再把开发轨迹与既有状态对齐以识别不一致之处，目标是提升智能体对技能的执行合规性。

Minghao LI

用 GPT-6-Astra 做机器人操作：身体知识、经验复用、涌现技能与 Sim2Real 迁移（Robot Manipulation with GPT-6-Astra: Body Knowledge, Experience Reuse, Emergent Skills, and Sim2Real Transfer）arXiv 2609.31770

通用多模态智能体可以编写机器人控制程序，但反复探索与模型介导的动作选择会让执行变慢。论文研究外部身体知识、成功经验与可执行技能如何提升由 GPT-6-Astra 控制的 XLeRobot 在仿真与真实电梯按钮任务上的表现：在 30 次固定起点仿真试验中，提供完整机器人几何与相机信息比「仅有通用控制接口、无先验经验」的基线把平均完成时间降低 57.4%；仅提供与动作、状态记录同步的图像时降低 68.6%，且不需要额外的身体资产；在起点偏移 10–100 厘米的 9 组配对比较（18 次试验）中，在原始起点记录的经验把平均时间降低 58–63%，说明对测试过的新起点具有泛化能力。

Sida He, Lingxi Xie, Yunning Cao, Pengfei Chen, Kaiwen Duan, Jiannan Ge, Xinyue Huo, Jiacheng Shao

RAZOR：裁剪大模型中的可替换专家（RAZOR: Pruning Replaceable Experts in LLMs）arXiv 2609.30465

混合专家（MoE）模型每个 token 只激活少量专家，却要存储整个专家池，裁剪该池的关键在于识别哪些专家移除后能保持模型行为。论文指出现有依据不充分：路由频率与输出幅度并不能完整描述删除造成的伤害，伤害还取决于存活专家与替换专家如何补偿被移除的输出。作者提出免训练的裁剪方法 RAZOR，基于「共识残差」——专家输出相对其原始加权混合的偏差。在固定层输入下，这些残差给出了在存活专家重归一化与路由器回填条件下的单次删除的精确输出变化；RAZOR 用条件均方根聚合该伤害，在逐层预算约束下仅靠前向计算选择专家，不需要梯度、子集搜索或恢复训练。

Mingyang Song, Mao Zheng
