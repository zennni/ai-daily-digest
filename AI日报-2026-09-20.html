this-that-model-1.0：30 毫秒出结果的类型化决策模型（this-that-model-1.0: A typed decision model that decides in 30 ms, for a millionth of a cent）arXiv 2609.23886

软件把越来越多的分支交给模型判断：工单进哪个队列、命令是否安全、理赔能否自动结案；程序需要的不是一段散文，而是 n 个预设选项中的一个加上一个可比较阈值的数。本文提出一个 2B 参数的类型化决策模型，答案直接从一个指定位置的隐状态读出并限制在调用方声明的选项集合内，因此不生成任何 token、不存在格式错误的可能，一次前向即可回答请求中的所有问题。在单张笔记本 GPU 上决策耗时 30.9 毫秒，而调用前沿 API 平均需 8758 毫秒。

PrimeSeeker：面向深度搜索智能体的能力导向监督（PrimeSeeker: Capability-Oriented Supervision for Deep Search Agents）arXiv 2609.35816

以往训练搜索智能体的合成问题，靠更大的证据图、更多跳数和更长轨迹来加大难度，但这些全局属性只是检索能力的间接代理。论文提出「潜在锚点推理」这一基础检索单元：先从描述性规格中定位一个未被命名的检索锚点，再把该锚点转移到后续的信息需求上，从而把深度搜索拆成相互耦合的操作链，并围绕锚点解析与关系迁移来构造问题，而不预设唯一搜索路径。基于该形式化提出 PrimeSeeker 框架，联合推导问题与答案，使监督信号直接对齐所需能力。

Linzhi Peng, Hanting Chen, Heng Chang, Ke Cheng, Bowen Du, Weifeng Lv

大推理模型的效率与安全两难（On the Efficiency-Safety Dilemma in Large Reasoning Models）arXiv 2609.23587

量化与剪枝被广泛用于压低大推理模型的推理成本，但它们对对抗鲁棒性的影响此前几乎没被系统检验。论文首次全面分析效率、越狱脆弱性与推理能力三者的相互作用，发现效率手段表面上降低了越狱成功率，但这种「改善」大多是假的——原因是推理能力退化导致恶意回答「尝试了但没做成」，而非对齐真的变强。对表示漂移的机制分析证实，推理能力损失与模型维持恶意语义轨迹的能力下降是严格耦合的；此外作者识别出量化与剪枝在特定组合下的额外风险。

Yifei Yang, Zouying Cao, Xingrui Wang, Xiao Zhou, Yuexian Li, Dongjie Yang, Hai Zhao

用分块感知的 KV 缓存管理把 LLM 服务接上 CXL-SSD（Bridging LLM Serving and CXL-SSDs with Chunk-Aware KV Cache Management）arXiv 2609.26828

NAND 存储能提供扩展前缀缓存所需的容量，但块 I/O 路径除 NAND 延迟外还带来 CPU 缓存争用与主机 DRAM 暂存开销；实验刻画显示即便以 DRAM 为介质这些接口成本依然存在，这也是引入可字节寻址的 CXL-SSD 的动机。但测试发现市售 CXL-SSD 仍比本地 DRAM 慢约 3 倍、与 NVMe SSD 相比也没有更快，通用预取几乎无收益。论文提出面向 LLM 前缀缓存的专用设计 LM-CXD：让 KV 分块成为设备可见的 I/O 单元，向服务引擎暴露 NAND 到 DRAM 的搬运进度，并把设备 DRAM 当作 GPU 可访问的缓冲区，从而把「引擎知道哪些 KV 将被消费」与「设备控制其放置与搬运」这两个语义层打通。

Hyunsun Chung, Taewan Noh, Minji Kim, Joo-Young Hwang, Hong-Yeon Kim, Youngjae Kim

VibeMemBench：在真实仓库编码任务上评测编码智能体的记忆系统（VibeMemBench: Evaluating Memory Systems for Coding Agents on Real Repository Coding Tasks）arXiv 2609.23570

编码智能体的持久记忆系统承诺跨任务复用经验，但既有评测无法回答这些系统是否真的提升了可执行的仓库级工作：仓库基准只测代码改动、无法隔离记忆的作用，记忆基准只给召回打分、不测下游编码结果。论文提出 VibeMemBench，覆盖来自 90 个 SWE-rebench V2 仓库的 111 个编码目标与 3634 条历史轨迹，任务类型包括缺陷修复、功能请求、接口变更与配置修改；智能体在明确声明的记忆条件下编辑代码库，最终由可执行测试判分，且只有注入历史经验能真实改善执行结果的目标才会被保留。

Liyang Fan, Yingcheng Shi, Yongbin Li, Chenghao Sun, Xin Chen, Xander Xu, Hu Wei, Shiwen Ni
