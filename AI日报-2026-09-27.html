Vestrum：通过改写验证、结构与记忆来改进 Agent Harness（Vestrum: Improving Agent Harnesses by Adapting Their Verification, Structure and Memory）arXiv 2609.33822v1

Agent Harness 决定了模型如何取信息、用工具、保留记忆与自查，但每次评估都要跑一长段真实交互，改进成本极高。论文提出 Vestrum：不训练任务模型，而是把执行轨迹里的失败归纳成可识别的失败类别，在验证、检索、分解与知识合成四个方向提出改动，先筛作用范围再成包评估，并用一个持久化的 lessons 文件指导后续提案。在五个设置、两个基线 harness 上，冻结的 harness 在留出集上都有提升，例如 UltraHorizon 从 47.6 升到 59.8。

Jayant Parashar, Eugene F. Douglass, William C. Bastian, Suchendra M. Bhandarkar
arXiv ↗

UOPD：面向多轮智能体在策略蒸馏的不确定性感知干预（UOPD: Uncertainty-Aware Intervention for On-Policy Distillation of Multi-Turn Agents）arXiv 2609.34036v1

多轮环境里的在策略蒸馏中，一个关键决策步的错误会把整条 rollout 带向失败。论文用「教师对学生动作的置信度低」来挑选高不确定步做纠正，并在受控的 ALFWorld 实验中验证：在低置信步做一次教师纠正，能改善学生后续行为与任务成功率。据此提出 UOPD——低不确定轮次让学生自己执行并施加标准 OPD 损失，高不确定轮次采样并执行教师动作、用监督微调让学生模仿。

Wenbo Zhang, Pengcheng Xu, Weizhi Du, Jing Zhang, Hengrui Cai
arXiv ↗

R² Flow：以递归技能演化实现递归自我改进（R² Flow: Recursive Self-Improvement via Recursive Skill Evolution）arXiv 2609.33867v1

智能体可以靠复用与修订编排出的技能流程实现跨任务自我改进，但这条循环有三个障碍：基于流的训练在树状历史上会发生策略坍缩；非负的流式信用把「被频繁使用」等同于「有收益」；技能库的编辑又直接依赖策略正在优化的任务奖励。论文提出 R² Flow，在共享状态编排图上交替做策略学习、独立验证与带版本号的技能库更新，图结构会合并只在独立步骤顺序上不同的历史，使流式训练可以跨等价路径汇集证据。

Mingda Zhang, Qiang Huang, Yanjin Li, Zijia Wang, Qika Lin, Xiaoying Tang, Tiesunlong Shen

扩散奖励模型：把奖励建模还原为条件密度估计（Diffusion Reward Models）arXiv 2609.33803v2

主流奖励模型把每个「提示-回复」对压缩成一个点估计，或压缩为某个固定参数族的分布，这与人类偏好的多峰特性不符：同一条回复可以合理地得到多种评价。论文提出 DRM，把奖励建模改为对条件密度 p(r|x,y) 的估计——在冻结的 LLM 编码器之上，用轻量的 Diffusion Transformer 把高斯噪声去噪成奖励向量，不对输出分布做参数假设，天然表达多峰结构。同一架构同时处理多属性回归与成对偏好数据，推理时 N 次采样构成经验分布。

Xiangyang Wang, Bingxiang He, Zeyuan Liu, Jiaze Wang, Ziqing Qiao, Yuxin Zuo, Huan-ang Gao, Cheng Qian
arXiv ↗

安全重构：用掩码扩散的生成式建模做更强的安全护栏（Safety Reconstructed: Generative Modeling via Masked Diffusion Builds Strong Safety Guardrails）arXiv 2609.33634v1

护栏模型是模型与有害输出之间的最后一道防线，但它的训练目标异常狭窄：现有护栏只从对话上下文预测一个判定 token，监督集中在一个目标上。后果是结构性的——模型抓住捷径特征、过度自信，且对「安全证据出现在序列什么位置」比对其在完整上下文中的作用更敏感。论文换了一个框架：不问「这段文本对应哪个标签」，而问「哪个标签更能解释这段文本」，分别对每条标签假设给提示或回复打分，再按分差分类，把监督铺到被审核区域的每一个 token 上，并用 LLaDA 系实例化。

Gert Lek, Abele Malan, Chaoyi Zhu, Pin-Yu Chen, Robert Birke, Lydia Chen
