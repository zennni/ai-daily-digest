前沿论文 5

cmHC：在伯克霍夫多胞形里「收缩」，平衡超连接的残差流混合

cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction · Haowei He, Ziwen Zhao, Chenshuo Pan 等（13 位作者）

流形约束超连接（mHC）把残差连接扩成多条流，并把流间混合矩阵限制在双随机矩阵构成的伯克霍夫多胞形上以稳定传播。作者指出其中存在混合权衡：矩阵贴近多胞形顶点时混合不足，多条流退化为近乎独立；集中在均匀重心附近时混合过度，流之间难以区分。作者对跨层累积混合、流差异与梯度差异给出界，提出精确保持双随机性的 cmHC：把多胞形几何地向内部收缩，迫使残差矩阵往内部探索，并带有可证明的混合界、不引入新参数；在浅层施加适度收缩以防过度混合，从而在超大规模预训练中保持梯度稳定。实验覆盖多种规模的稠密与 MoE 模型。

https://arxiv.org/abs/2611.27193

不穿模的世界模型：从冻结 DiT 的隐藏状态读出「这一步会不会穿墙」

Non-penetrating World Models · Yuhang Dai, Yinwei Wu, Ziyue Lin, Han Ji, Xingyi Yang

交互式视频世界模型常让物体穿过障碍物。作者提出 NoPeBench 评测世界模型对物理障碍的反应，发现开源模型都无法可靠避免穿模，但扩散 Transformer 的隐藏状态其实已编码了预测穿模所需的信息。据此提出轻量框架 NoPeWorld：在冻结 DiT 的隐藏状态上训练一个小预测头判断候选动作是否安全，把不安全动作替换为最接近原意的安全动作。六个视频世界模型的平均物理违规率由 74% 降到 16%，并能零样本泛化到开放域图像、第三人称视角与移动障碍。代码、基准与权重已公开。

https://arxiv.org/abs/2611.27963

Future-OPSD：用无标注视频的「过去—未来」配对做在线自蒸馏，学会预判下一步

Learning Video Foresight Reasoning from Unlabeled Videos via On-Policy Self-Distillation · Jingchen Sun, Jiaxing Zhang, Qingqiao Hu 等（10 位作者）

视频前瞻推理要求模型从当前画面预判未来事件或下一步动作。现有方法依赖标注或外部大模型监督，并把整段未来片段视为同等重要。作者把过去—未来视频对直接变成自监督信号，定义「前瞻分数」并由此得到对比特权优势，用一个可优化的下界替代项把真实未来与随机参照之间的优势与师生蒸馏优势结合，放大与决策相关的内容、压低无关上下文。在开放式预测与封闭式规划上，相对基座分别最多提升 14.2 与 15.9 分，且不损害一般视频理解。

https://arxiv.org/abs/2611.26954

MemOnce：只缓存少量末层隐藏状态、按需解码回 KV 的可扩展记忆架构

MemOnce: A Scalable Memory Architecture for Large Language Models · Chang Nie, Chaoyou Fu, Songlin Liu, Yiqing Hu, Caifeng Shan

标准 Transformer 的逐层逐 token KV 缓存随上下文线性增长，线性时间架构又把历史压成固定大小状态、难留细节。MemOnce 用两项设计折中：记忆编码—解码器只缓存一小部分末层隐藏状态作为紧凑记忆，需要时动态解码回各注意力层的 KV；记忆稀疏注意力为每段连续输入自适应检索相关记忆，稀疏索引跨层只算一次。作者称它在不同模型规模、上下文长度与训练范式下优于 Transformer 等架构；用 MemOnce 改造 Qwen3.5-4B 后，记忆状态缓存缩小约 1313 倍。

https://arxiv.org/abs/2611.27973

StereoVLM：用标定双目视觉做度量级 3D 空间推理的视觉语言模型

StereoVLM: Binocular Vision-Language Models for Metric 3D Spatial Reasoning · Chi Yan, Guoyang Zhao, Wentao Yuan 等（6 位作者）

现有视觉语言模型多从无标定的单张或多张图像推断三维结构，度量信息天然模糊，也说不清预测是依据视觉证据还是语义先验。作者提出几何感知的双目 VLM，按「跨视图对应与视差估计 → 标定条件下的度量深度 → 语义空间推理」分层学习，并发现视差监督在未见环境中的泛化明显好于直接的双目深度监督。配套 Stereo3D-Bench 覆盖点级几何到物体级空间推理三个层次；StereoVLM-8B 深度准确率（δ1）为 95.17%，物体级平均得分 66.98。

https://arxiv.org/abs/2611.27915

ZDNet 报道，Anthropic 周一以测试版推出 Claude Ship，称「Claude 现在可以审查 PR、修复它们，并批准团队政策允许的那些」，面向 Team 与 Enterprise。流程由三部分组成：3 月推出的 Code Review 汇总并发布审查意见；PR Steward 处理失败的 CI 检查、合并冲突与来自 Code Review、其他工具或同事的评审意见，并在每次推送里写明改了什么、如何撤销，但它不能批准或合并；Claude Approvals 按团队政策决定是否批准。Anthropic 称团队仍控制在哪里运行、哪些改动必须由人确认。
